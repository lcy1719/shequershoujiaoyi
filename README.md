## 【系统功能模块】
1. 前台小程序
这是用户与小程序进行交互的主要界面，用户可以在此浏览商品、搜索商品、购买商品、查看订单、参与论坛讨论等。
2. 管理员管理
管理员登录后可以管理小程序的各项功能和数据，包括用户管理、商品信息管理、论坛管理等。
3. 用户管理
（注意：此功能被列出了两次，可能是重复）管理所有使用小程序的用户账户，包括用户注册、登录、个人信息修改、密码重置等。管理员可以查看用户的交易记录、评价记录等，以监控用户行为。
4. 商品信息管理
管理员可以添加、编辑、删除商品信息，包括商品名称、描述、价格、图片等。用户也可以在自己的账户下发布自己的二手商品信息。
5. 论坛管理
提供一个论坛区域，让用户可以发布二手交易心得、交流使用经验、发布求助信息等。管理员可以管理论坛的帖子，如删除违规内容、置顶重要信息等。
6. 收货地址管理
用户可以在此管理自己的收货地址，以便在购买商品时能够正确填写收货信息。用户可以添加、编辑、删除自己的收货地址。
7. 基础数据管理
管理小程序中使用的各种基础数据，如交易规则、交易流程、支付方式、配送方式等。这些基础数据为小程序提供了必要的支持，确保其他功能的正常运行。
8. 新闻信息管理
发布和管理与二手交易相关的新闻信息，如市场动态、交易提醒、安全指南等。这些新闻信息可以在前台小程序中展示，帮助用户更好地了解交易环境和注意事项。
9. 轮播图信息
管理员可以上传、编辑和删除轮播图信息，用于展示热门商品、促销活动、社区风采等。轮播图可以在前台小程序的首页或相关页面循环展示，吸引用户的注意力。
